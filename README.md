# 二年级（K12）学习工作台 · 开源生成器

把一套**单文件离线 HTML** 学习工作台（语文/数学/英语/科学/体育/阅读/劳动/奖励）做成**可复用、可换教材版次**的开源工具。
别人下载本仓库 → 按提示补齐自家孩子的教材资料 → 构建 → 得到一个**双击即用、可装 PWA** 的专属工作台。

## 它解决什么
- **单文件离线**：所有图片 base64 内嵌、进度存 localStorage，不依赖服务器。
- **换地区/换教材 = 换内容包**：教材内容（课表、词语表、单词、例题、作息）全部外置成 `内容包 JSON`，构建时内联进模板。不改代码。
- **版权安全**：不扫描课本原文，插画由 AI 重画；词语表按课本**印刷体**逐字录入，AI 不猜。

## 三步上手（给最终用户）
1. **备资料**：按 `ONBOARDING.md` 的清单拍课本照片（目录页 / 词语表页 / 单词页 / 例题页 / 拼音表 / 科学页，要求正拍、单页、清晰）。
2. **出内容包**（二选一）：
   - **脚本模式（推荐，自带视觉大模型 key）**：`node tools/extract_from_photos.mjs --map "CN:语文.jpg;MA:数学.jpg;EN:英语.jpg" --api-key sk-xxx --base-url <视觉API>/v1 --model <模型> --id <版次> --region <地区> --grade <年级> --out draft.json`，先 `--skeleton` 生成空骨架、再用 `--map` 分组抽；`--dry-run` 可预览提示词不调 API。
   - **agent 对话模式**：把照片在 WorkBuddy 类 agent 里一张张上传，agent 按 `schema/CENT_PACK.md` + `ONBOARDING` 抽取。
   - 两种都产出 `draft.json`（草案），**必须按 `ONBOARDING.md` 核红清单人工核对**后才能构建。
3. **构建 + 门禁 + 用**（一键入口，纯 Node、无需 Edge/Python）：
   ```bash
   node tools/make.mjs template.html draft.json dist/工作台.html
   ```
   它会：① 把内容包内联进模板生成单文件 HTML；② 跑**版次无关结构自检门禁**（锚点完整 / 语法 / 基线 / 跨引用静默坏防护 / 作息完整）。门禁通过才放行产物。
   双击 `dist/工作台.html` 即可；想多设备同步/装 PWA，自行托管到任意静态空间（GitHub Pages 等）。

> 环境要求：只需 Node.js（v18+）。门禁与构建**不依赖**无头浏览器或 Python，跨机即跑。拍照抽取需一个**视觉大模型 API key**（自己填，脚本不内置任何 key）。

├─ SKILL.md                   # 方法 + 铁律 + 发布闭环（开发者读）

## 门禁（版次无关，重点）
`gate_pack.mjs` 取代原项目写死的 `DATA:236/36/25/240/2/13` 与 `COV:40/40,13/13`，**所有基线都从内容包实时计算**：
- **锚点完整**：模板里每个 `/*__PACK:NAME__*/` 在产物中都被替换，无残留（构建忠诚）。
- **语法体检**：产物主 `<script>` 能编译。
- **基线计算**：复刻产品的 `allWords` / 易错点覆盖语义，算出 `DATA`/`COV` 并报告（不写死任何地区数字）。
- **内部一致**：各科目条目数 > 0、四套作息块数 > 0、节假日/调休日期合法。
- **跨引用静默坏防护**：`MA_ERR/MA_EX/SC_DO/SC_EX` 不得有「悬空键」（键必须存在于课表，否则例题/易错点静默消失）；`ENGLISH` 单元数 == `EN_CUR` 单元数（英语双副本同步）。
- **作息完整**：每块 `t≤e`、区间块 `dur` 与时长一致、同日内不重叠、`type` 在允许集合内（单点块如「熄灯」`t==e` 合法）。

验证示例（深圳包）：门禁算得 `DATA:236/36/25/240/2/13`、`COV:40/40,13/13`，与历史写死值一致；人为注入「悬空键 + 起>止作息」时门禁准确拦截并退出非 0。

## 给开发者的门禁
- 改完内容包必跑 `make.mjs`（构建 + 门禁一体）；首次迁移现有 HTML 时跑 `verify_roundtrip.mjs`（确认外置↔重建零丢失）。
- 内容基线由脚本从内容包算，**不要**硬编码数字到断言里。
- 完整回归见 `SKILL.md` §4（原项目 9 套门禁已抽象为上述版次无关门禁）。
